=== SLIDE 3 ===
Document purpose
Purpose
The purpose of this document is to provide an overview and definition of the Frontier Accelerate for Copilot Program and details on the post-sales engagement:
Agent Solution Deployment Accelerator
This delivery guide outlines a flexible engagement model. For each step, the guide provides a delivery structure, engagement delivery examples, and discusses necessary activities, assets and resources you may need to familiarize yourself for this engagement.
Audience
This document is intended to be used by partner sellers, practice leads, project managers, field consultants, and other partner resources with competencies in Microsoft 365 Copilot, Copilot Studio, Microsoft Foundry, Agent 365, Agent SDK and/or Microsoft Power Platform.
Assumptions
Partner resources involved in the delivery of these engagements have read and understand the content of this delivery guide.
Partner understands that this document is not intended to be shared directly with customers.
Other notes
If you believe you have found an error or have a suggestion for improving this document, please complete this form.

Agent Solution Deployment Accelerator| What’s new!
Frontier Accelerate for Copilot
New Frontier Accelerate post-sales engagement for FY27!
This FY27 Agent Solution Deployment Accelerator is focused on building agentic solutions leveraging Copilot Studio, Microsoft Foundry, Agents SDK, and Agent 365 SDK, Power Platform and/or managing them with Agent 365, a governed platform.
This accelerator maintains the flexible engagement structure from FY26.
FY27 MCI eligibility includes SME&C expansion. Please review the MCI Incentives Guide for this year’s partner and customer eligibility criteria.
New updates!
New Copilot Cowork Engagement Delivery Guidance
New Agent 365 PoC Kit
Ways to build, secure, and govern agents in this accelerator
Copilot Studio – Low-code authoring for agents, with knowledge grounding, tools/actions, and flexible channel publishing.
Microsoft Foundry – Pro-code path for prompt, workflow, or hosted agents with custom models and stable endpoints.
Agent 365 SDK – Create new agents and bring third-party and existing agents into Agent 365 with built-in identity, Work IQ tooling, telemetry, and controlled Microsoft 365 access.
Custom Declarative / Agents SDK – Agent Builder in Microsoft 365 Copilot, Agents Toolkit, or the Microsoft 365 Agents SDK for declarative or custom-engine agents.
Power Platform – Power Apps, Power Automate flows, and Dataverse-backed solutions for scalable, automated workflows.
Agent 365 – Governed control plane for registry, identity, security, observability, and lifecycle management.

=== SLIDE 13 ===
Engagement approach
DELIVERING PARTNER IMPACT
This engagement is flexible and modular. Partners can choose to deliver any combination of activities and utilize any set of resources and assets provided in this guide or use their own assets. This may be based on partner preference, customer requirements or other considerations.
Recommended approach:
Identify priority scenarios, value, and readiness. Use opportunity framing, use cases, governance checklists.
Design and develop agent solutions. Use deployment accelerator assets, reference architectures, SDK guidance.
Operationalize, adopt, and expand. Use deployment guides, observability, adoption toolkits.
Partners may use Microsoft assets, extend with their own IP, or combine both.
Refer to the Frontier Accelerate for Copilot Program Guide and MCI Incentive Guide for minimum requirements for funding.
A reminder: Microsoft’s funding is a co-investment to support M365 Copilot Deployment Accelerator deliveries and is not intended to cover the cost of all the deployment, implementation or adoption work.

Activity category
Activity category definition
Scenario Discovery & Solution Design
This category includes activities related to the process of identifying and prioritizing high-value business scenarios that can unlock further potential with Microsoft 365 Copilot, agents, Agent 365 and Power Platform.
Business Value Analysis, Measurement, & Reporting
This category includes activities across the end-to-end value stream, such as defining methods to qualify and quantify value, setting business objectives, establishing value metrics, measuring cost and value, and realizing value outcomes.

This category includes art-of-the-possible experiences showcasing Frontier Transformation demos, customer stories, and product pitch decks

This category includes activities related to the delivery of information, planning, configuration, development, setup, and technical deployment activities in support of security, compliance, and governance frameworks, technologies, reporting and operations.

This category includes activities related to the technical design, development, testing, and deployment of a service, agent, application, automation, or non-technical initiative designed to deliver business value.

This category includes activities related to the administration, operations, setup, configuration, monitoring, and maintenance of a platform, a service, cloud infrastructure, platform and application features and other elements which require ongoing administration.

This category includes activities related to the transfer of knowledge, learnings, skills, and capabilities to Champions, end users, administrators, and other stakeholders – ultimately driving greater adoption and utilization of a platform, service, solution, or technical capability.
