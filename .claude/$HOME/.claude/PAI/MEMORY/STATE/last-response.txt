**On the hotkey scope levels** (from the transcript):

In Mindmap Builder v3, open the **side panel → Hotkey Configuration**. Each hotkey has three scope icons next to it:

| Icon | Scope | When it fires |
|------|-------|---------------|
| ⌨️ Keyboard | Input box | Only when the text input field is focused |
| 🌐 Globe | Global | Anywhere in Obsidian — use sparingly to avoid conflicts |
| Excalidraw icon | Excalidraw | Any time the Excalidraw canvas is active (most common choice for navigation) |

Click the icon next to a hotkey to toggle its scope. Navigation keys (arrow keys, zoom, enter) work best at **Excalidraw scope** so you don't need to click into the input box first. Only assign **Global scope** to things like the launch hotkey itself (set via Obsidian's main hotkey settings, not inside the panel).
