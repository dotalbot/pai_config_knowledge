## Mindmap Builder Hotkeys — Complete Reference

### Setting up the global hotkey (to launch Mindmap Builder)
- Go to **Obsidian Settings → Hotkeys**, search for **"mindmap builder"**, assign any key combo you want
- When triggered: opens the panel if docked, or the floating box if undocked — persistent state

### Built-in Hotkeys (inside Mindmap Builder)

| Key | Action |
|-----|--------|
| `Enter` | Create central node / move to next sibling |
| `Ctrl/Cmd + Enter` | Add child node, keep focus on new child |
| `Shift + Enter` | Add child and close edit box |
| `Ctrl/Cmd + Shift + Enter` | Pin/unpin a node's location |
| `Alt + Arrow Keys` | Navigate between nodes |
| `Alt + Ctrl/Cmd + Arrow Keys` | Navigate + centre the selected node on screen |
| `Alt + C` | Copy branch to clipboard (as markdown) |
| `Alt + V` | Paste branch |
| `Alt + X` | Cut branch |
| `Alt + B` | Toggle box/rectangle around a node |
| `Alt + M` | Activate the input field from anywhere |
| `Alt + Z` | Cycle through 3 zoom levels |
| `F2` | Open a node for editing |
| `Ctrl/Cmd + K` | Add an element link |
| `Tab` | Move between buttons in the floating input (v3) |

### Configuring hotkeys inside Mindmap Builder
- Dock the panel → scroll to **Hotkey Configuration** at the bottom
- Press `+` next to any action to assign your own key combo
- Three **scope levels** control when hotkeys fire (v3):
  - **Input box scope** — only fires when the text input is focused
  - **Excalidraw scope** — fires any time the Excalidraw canvas is active
  - **Global scope** — fires anywhere in Obsidian (use sparingly to avoid conflicts)
